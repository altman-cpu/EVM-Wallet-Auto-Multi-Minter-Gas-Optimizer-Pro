# Open / Close & Shift Checklist — Fuel Retail

**Rule:** Checklist = control. No photo/sign-off = not done. Store PDF as `ops/logs/YYYY-MM-DD-shift.pdf`.

## Opening (AM Manager)

- [ ] ATG reading recorded ___ gallons (photo of ATG screen)
- [ ] All pumps tested: receipt prints, display matches POS
- [ ] Price sign = POS = pump (initials ___)
- [ ] Cooler temps 33-40°F, freezer <0°F (photo thermometer)
- [ ] Cash drawer counted $___ by ___ / verified by ___
- [ ] Safety: fire extinguisher, spill kit, nozzles clean
- [ ] Lottery / tobacco count verified vs previous close

## Midday / Shift Handover

- [ ] Safe drop $___ count, bag #___, two signatures
- [ ] Out-of-stock list updated (top 10 SKUs)
- [ ] Restroom/c-store cleanliness photo
- [ ] Fuel delivery? BOL #___ gallons ___ checked vs ATG

## Closing (PM Manager)

- [ ] Cash variance calculated (expected $___ / actual $___ / diff $___)
- [ ] POS Z-report printed + attached
- [ ] Trash, car wash, and forecourt swept (photo)
- [ ] Doors locked, cameras confirm, alarm set

## Exceptions (must explain)

- Pump offline #: ___ Reason: ___ Ticket #: ___
- Price change requested by ___ approved by ___ time ___ (attach POS log)
- Any void/refund >$20: receipt # ___ reason ___ manager initials ___

> Owner review daily: any unchecked box = conversation that day. Pattern of exceptions = system fix, not just coaching.
